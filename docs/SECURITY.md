# Public Repository Safety

This repository is public.

Do not commit:

- credentials, tokens, private keys, or certificates
- production IP addresses, hostnames, ports, or firewall rules
- customer or supplier identifiers
- real balances, tariffs, CDRs, Call-IDs, or incident evidence
- internal topology or HA details
- private operational runbooks
- proprietary commercial policy

Use synthetic examples and placeholders for all public documentation and tests.
